# Deep Learning Experiment 2

## Aim
To compare different activation functions and optimization algorithms in Artificial Neural Networks.

## Software Used
- Python
- TensorFlow
- Google Colab
- GitHub
- Matplotlib

## Experiments

### Part A
Visualization of Sigmoid, Tanh and ReLU activation functions.

### Part B
Comparison of activation functions using an ANN model.

### Part C
Comparison of optimization algorithms:
- SGD
- Momentum
- RMSProp
- Adam

### Result
ReLU achieved the best performance among activation functions.
Adam optimizer converged faster and achieved the highest accuracy.
